Wire SageCollection.nftDeployer 🧩

Collection (ZIP) drops cannot deploy their per-drop NFT contract on mainnet. createCollectionWithNewNft opens with require(nftDeployer != address(0), "Deployer not set"), and nftDeployer has never been set.

Why this is two transactions and not one. The obvious fix — point SageCollection at the DedicatedNftDeployer that already exists — does not work. That deployer's allowedCaller is the server signer, because the server calls deploy() directly when it creates open editions and auctions. deploy() admits exactly one caller, so repointing it at SageCollection would break the path that currently works. Hence a second deployer, same bytecode, whose allowedCaller is SageCollection. That single check is the only thing standing between deploy() and anyone minting a genuine-codehash SageNFT that names an unrelated wallet as its artist, so it stays exactly that tight.
