Set trustedNftReference 🔓

This is the ONE remaining thing stopping a normal wallet from putting a drop on sageart.xyz. Both game contracts gate creation with onlyAdminOrArtist, which allows the NFT contract's artist — but only if _isTrustedNft() passes, and that requires trustedNftReference to be set. It is currently address(0) on both, so the second clause is always false and the modifier collapses to admin-only.

Two setTrustedNftReference transactions, signed by an admin (0x3E099aF007CaB8233D44782D8E6fe80FECDC321e). The reference is only ever read for its runtime codehash — never called into — so pointing it at a real SageNFT deployed by the current factory makes every future deployByArtist contract match.
